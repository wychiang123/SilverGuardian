# Roadmap

本文件根據目前 SilverGuardian 程式碼狀態推導，整理後續改善方向。此 roadmap 不代表已承諾功能，僅作為專案演進建議。

## 近期目標

### 1. 文件與專案說明補齊

目前 README 已從 React Native 預設內容改為專案說明。後續可補上：

- 開發環境設定。
- Android 與 iOS 實機測試流程。
- `.env` 範例。
- OpenAI 與 SendGrid 設定方式。
- 權限說明。
- 常見問題。

### 2. 測試環境修正

目前 Jest 可能因 React Navigation ESM 模組而無法順利執行。

建議：

- 設定 Jest transform。
- mock React Navigation。
- mock native module，例如錄音、圖片選取、行事曆、AsyncStorage。
- 讓基本 render test 可穩定通過。

### 3. 抽出詐騙規則引擎

目前詐騙關鍵字、白名單、分數計算與最終風險合併邏輯位於 `ScanScreen.tsx`。

建議移至獨立模組，例如：

```text
src/services/scamRuleEngine.ts
src/services/scamRiskService.ts
```

好處：

- 可對規則引擎撰寫單元測試。
- 畫面邏輯更簡潔。
- 後續可調整規則而不影響 UI。
- 可建立測試案例集驗證誤判與漏判。

### 4. 強化 AI 回傳防呆

目前 OpenAI 回傳內容直接 `JSON.parse`。

建議：

- 加入 schema 驗證。
- 補上預設值。
- 處理模型回傳不合法 JSON 的情境。
- 對 `risk_level`、分數、陣列欄位做型別與範圍檢查。

### 5. 改善敏感資訊管理

目前 App 端直接讀取 OpenAI 與 SendGrid key。

建議：

- 建立後端代理服務。
- API key 只保留在後端。
- 手機端只呼叫自家 API。
- 後端統一處理驗證、rate limit、成本控制與錯誤記錄。

## 中期目標

### 1. 後端服務

推測正式產品需要後端服務支援：

- OpenAI API proxy。
- SendGrid notification proxy。
- 使用者或裝置識別。
- 伺服器端 rate limit。
- API 成本控管。
- 安全稽核。
- 錯誤追蹤。

### 2. 隱私與同意流程

應用會處理圖片、語音、文字與家人 Email。

建議新增：

- 首次使用隱私說明。
- 上傳至第三方 AI 服務的明確提示。
- 高風險通知家人的明確同意。
- 資料保存與刪除說明。
- 正式環境停用敏感 console log。

### 3. 語音記錄體驗強化

可改善方向：

- 顯示錄音秒數。
- 支援取消錄音。
- 支援重新錄音。
- 支援手動編輯 AI 分類結果。
- 儲存前顯示更完整的確認畫面，而不只使用 Alert。

### 4. 詐騙辨識體驗強化

可改善方向：

- 掃描前提示如何截圖或拍攝。
- 結果頁提供更明確的下一步建議。
- 高風險時提供一鍵撥打家人或官方反詐騙專線。
- 低信心時引導使用者補拍或請家人協助。
- 將 debug 資訊改為開發模式才顯示。

### 5. 歷史記錄功能擴充

目前歷史頁只保存語音記錄。推測後續可考慮：

- 保存圖片詐騙掃描結果。
- 依類型篩選。
- 搜尋記錄。
- 匯出記錄。
- 編輯或補充備註。

## 長期目標

### 1. 更完整的照護者模式

推測此產品可延伸為長者與家人共同使用的安全工具。

可能方向：

- 家人端通知中心。
- 多位照護者管理。
- 高風險事件摘要。
- 遠端設定家人聯絡資訊。
- 緊急聯絡流程。

### 2. 詐騙案例資料庫

可建立本機或後端詐騙案例資料庫：

- 常見詐騙關鍵字。
- 最新詐騙手法。
- 可更新規則包。
- 本機離線初步判斷。

此項目前程式中尚未看到實作，屬於推測方向。

### 3. 模型與成本最佳化

可根據使用情境調整：

- 圖片壓縮策略。
- OCR 與 AI 分析拆分。
- 高風險才使用較昂貴模型。
- 低風險或明確白名單內容使用本機規則。
- 後端集中監控 token 與請求成本。

### 4. 品質保證與自動化

建議建立：

- 單元測試。
- 畫面測試。
- 規則引擎案例測試。
- API mock 測試。
- Android/iOS smoke test。
- CI 檢查 TypeScript、lint、test。

## 優先順序建議

### P0：上線前必要

- 移除手機端直接暴露 API key 的架構。
- 修正測試環境。
- 建立基本錯誤與隱私處理。
- 將敏感 console log 移除或限制在開發模式。

### P1：核心品質

- 抽出並測試詐騙規則引擎。
- 強化 OpenAI JSON 回傳驗證。
- 改善高風險通知失敗處理。
- 改善權限拒絕時的使用者引導。

### P2：產品體驗

- 改善語音確認流程。
- 儲存圖片掃描歷史。
- 加入更清楚的結果建議。
- 增加家人聯絡方式與通知偏好。

### P3：擴充能力

- 後端管理介面。
- 案例資料庫。
- 多照護者模式。
- 成本分析與模型策略最佳化。
